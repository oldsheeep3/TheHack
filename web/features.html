MIX source

合成ソース

複数のソースを 1 枚のキャンバスに自由配置し、1 つのソースとして扱えます。

どこにでも置ける

MIX はカメラと同じ扱いです。バスに載せる／マルチビューのセルに置く／物理モジュールの スイッチに割り当てる、すべてそのまま動きます。

メンバーは共有

MIX に入れたカメラは、同時に単体でバスに載せられます。デバイスは 1 回しか開かれません。

編集

実寸のキャンバス上でドラッグ移動、右下の角でリサイズ。各レイヤーはライブのサムネイルで 表示されるので、実際の絵を見ながら composition を組めます。

プリセット

全画面 / 左半分 / 右半分 / 隅にワイプ。座標とサイズの数値入力、重ね順の前後移動も可能です。

Mix / Effect

2系統 M/E

独立した 2 バス

PGM1/PVW1 と PGM2/PVW2 は互いに影響しません。配信用と会場用で別の絵を同時に作れます。

CUT / AUTO

CUT は即時、AUTO はフェード（250 / 500 / 1000 / 2000 ms）。操作したバスにだけ作用します。

複数レイヤー

1 つのバスに複数のソースを重ねられます。並び順がそのまま重ね順になります。

Multiview

マルチビュー

4×4 〜 6×6

行と列を独立に選べます（正方形でなくても構いません）。セルはドラッグで矩形選択して結合、 分割で元に戻せます。

タリー枠

セルの内容がオンエアなら赤枠、プレビューにステージ中なら緑枠。カメラのセルも 同じルールなので、どの入力が本線かがひと目で分かります。

全画面表示

別のディスプレイに全画面で出せます。オペレーター画面と同じディスプレイを選ぶと警告します。

Outputs & control

出力と操作

Outputs

出力

仮想カメラ（Zoom / Teams などへ）、HDMI 全画面、NDI 送出。初期状態はウェブカメラ 1 つ＋ HDMI 1 つで、そこから HDMI と NDI を足せます（ウェブカメラ 1 つ、 HDMI・NDI はそれぞれ最大 3 つ、合計最大 6 つ）。それぞれ PGM1 / PGM2 のどちらを出すか選べます。 PGM1・PGM2 はそれぞれ最低 1 つの出力が必要です ── どこにも出ていない本線を作らないための決まりです。

ウェブカメラ出力は 1 つだけです。OBS が用意できる仮想カメラは 1 本しかないので、 2 つ目は中身が NDI 送出になり「ウェブカメラ」という名前が実際の出口を偽ってしまいます。 それを避けるために 2 つ目は追加できません ── もう 1 系統いるときは NDI 出力を足してください。

Audio

音声

映像ソースを追加すると音声も一緒に入ります。ソースごとに AFV（オンエア中 だけ鳴る）・ON（常に鳴る）・OFF を選択。合成ソースが オンエアなら、その中のソースの音も鳴ります。

出力は PGM1 / PGM2 が独立していて、それぞれ別の音声デバイスへ送れます。1 つのバスを 複数のデバイスへ同時に出すこともできます（会場 PA と収録機、など）。

Keyboard

キーボード

1–9 でステージ、Space で CUT、A で AUTO、Esc でプレビュークリア、Tab で M/E 切替。

Controller

物理コントローラー

Pico 2W ベースのモジュール式スイッチ。接続されているモジュールだけが 自動で画面に現れます。バックライトがタリーに追随します。

Web API

Web / API

同一ネットワークのスマホなどから操作するための REST API と WebSocket を内蔵しています （既定ポート 8080）。
