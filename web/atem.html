ATEM

ATEM 連携 準備中

Blackmagic ATEM Mini との連携について。ページは準備中ですが、現行アプリ側の対応状況を先に記載します。

ATEM Mini は 2 つの役割で使えます。1 つは映像の入力元 （SRT や NDI 経由で ATEM のプログラム出力を受ける）。もう 1 つは遠隔操作できる外部 スイッチャーとして、Switcher 側の操作を ATEM のコマンドへ中継することです。

現在対応していること

Relay

操作を ATEM コマンドへ中継

物理モジュールのスイッチや Web からの操作を、ATEM の Program / Preview 切替や Cut / Auto へ写像して送出します。写像はアプリ側で設定します。

Direct

コマンドの直接送信

API から任意の ATEM コマンド（アクション・M/E・入力番号）を 1 発送れます。

Status

接続状態の表示

コンソール上部に ATEM の接続状態を常時表示します。

Isolation

落ちても止まらない

ATEM が未接続・切断されていても、Switcher 本体の動作には影響しません。

このページには今後、接続手順・入力としての受け方（SRT / NDI）・ ボタン写像の設定例・想定する配線図を掲載する予定です。
