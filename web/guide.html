Guide

使い方

インストールから本番運用まで。所要 10 分程度です。

Setup

セットアップ

展開する

映像エンジン（OBS のコアである libobs とそのプラグイン）は配布物の obs-runtime/ に同梱しています。OBS Studio のインストールは不要で、 展開してそのまま起動できます。

すでに OBS Studio（30.0〜32.99）が入っている PC では、同梱物を消せばそちらを自動検出して 使います。場所を明示したい場合は appsettings.json の ObsInstallPath を 指定してください。

（任意）NDI Tools をインストールする

NDI の入出力を使う場合のみ必要です。NDI Tools に含まれるNDI ランタイムを Switcher が実行時に読み込みます。

OBS 用の NDI プラグイン（DistroAV）は不要です — Switcher は NDI を自前で実装しています。 NDI を使わないなら何も入れる必要はありません。

Switcher を起動する

起動すると映像エンジンが立ち上がり、前回の設定（入力・マルチビュー配置・出力・ モジュール割当）が復元されます。

バスは空の状態で起動します。起動しただけで映像が本線に乗ることは ありません。出す操作は明示的に行ってください。

Sources

入力を追加する

「+」を押す

Sources ドック右上の +（またはツールバーの「+ Add source」）で追加 フォームが開きます。

名前・種類・接続先を入れる

  • 名前 — バスのボタンに出るので、見て分かる名前を付けます
  • 種類 — WEBCAM / NDI / SRT / IMAGE / HTML
  • 接続先 — デバイス、URL、ファイルなど

カメラは「Capture mode」を確認する

「Device default」のままだとカメラが申告する既定モードで開きます。機種によっては これが極端に低いフレームレートです（実測で 8 fps の例あり）。映像がカクつく場合は 1280x720 @ 30 などを明示してください。

MIX を作る（任意）

ツールバーの「New mix...」で、複数のソースを 1 枚に合成したソースを作れます。 レイヤーをドラッグで移動、右下角でリサイズ。作った MIX はカメラと同じように扱えます。

On air

切り替える

基本の流れ

Buses ドックでソースのボタンを押す → プレビュー（緑）に載ります。 左の大きい画面で確認したら CUT（即時）か AUTO（フェード）で 本線へ。押した瞬間に PGM と PVW が入れ替わります。

キーボード

1–9 ステージ / Space CUT / A AUTO / Esc プレビュークリア / Tab M/E 切替。
文字入力中は無効になるので、名前を打っている最中に誤って切り替わることはありません。

色の意味

赤 = オンエア、 緑 = 次に出るもの。 マルチビューのセル、バスのボタン、ソースの枠すべてで同じ意味です。

すぐ止めたいとき

「Take this bus off air」で、そのバスを一発で無出力にできます。

Layout & output

マルチビューと出力

マルチビューを組む

ツールバーの「Multiview settings」で開きます。グリッドは 4×4 〜 6×6。セルをドラッグで 矩形選択して「Merge selected」で結合、「Split」で分割。各セルのドロップダウンで中身 （PGM1 / PVW2 / 各ソース / 空）を選びます。変更は即時反映・自動保存です。

別ディスプレイに全画面表示する

設定画面の「Show full-screen」、またはツールバーの「Multiview full-screen」。 Esc で閉じます。

出力を割り当てる

Outputs ドックで、各出力に PGM1 / PGM2 のどちらを流すか選び「Apply output routing」。

  • Vcam1 — 仮想カメラ。Zoom / Teams / Meet などがカメラとして認識します
  • Vcam2 / Ndi1 / Ndi2 — NDI 送出（映像と音声）
  • Hdmi — 指定ディスプレイに全画面

PGM1・PGM2 のそれぞれに最低 1 つ割り当ててください。全部を同じバスに 向けた設定は保存できません。

音声を出す

音声は映像ソースに付いてきます。Sources ドックの各行にある AUDIO で、 AFV（そのソースがオンエアの間だけ鳴る）・ON（常に鳴る。BGM や 司会マイク）・OFF を選びます。既定は AFV です。

出力先は Outputs ドック下部の AUDIO OUT。PGM1 / PGM2 それぞれに音声 デバイスを選び「Apply audio」。デバイスを後から挿した場合は「Rescan」で再列挙します。

Troubleshooting

うまくいかないとき

症状確認すること
起動に失敗する obs-runtime/ が配布物と一緒に展開されているか。インストール済みの OBS を使う設定なら そのバージョン（検証範囲は 30.0〜32.99。範囲外だと libobs の ABI が合わないことがあります）と appsettings.json の ObsInstallPath を確認してください
カメラが「no signal」 他のアプリがそのカメラを使っていないか。同じカメラを 2 つのソースにすることはできません （1 つのソースを共有してください）。復帰したら「Reconnect」を押します
音が出ない ソースの AUDIO が OFF になっていないか。AFV はオンエア中だけ鳴ります。 Outputs ドックで PGM1 / PGM2 に出力デバイスが割り当てられ、「Apply audio」を押したかも確認してください
出力が起動しない NDI 系の出力（Vcam2 / Ndi1 / Ndi2）は NDI Tools（NDI ランタイム）が入っていないと起動しません。 仮想カメラは他のアプリが使用中だと起動しません。どちらの場合も「Apply output routing」時に警告が出ます
出力ルーティングが適用できない PGM1・PGM2 のそれぞれに最低 1 つの出力が必要です。全部を同じバスに向けると弾かれます
映像がカクつく 「Capture mode」がデバイス既定になっていないか。明示的に 30 fps 以上のモードを選びます
NDI が一覧に出ない NDI Tools（NDI ランタイム）が入っているか。送信側と同じネットワークにいるか。数秒待ってから「Rescan」
モジュールが表示されない Controller ドックは実際に接続されているモジュールだけを表示します。 USB 接続とコントローラーのファームウェアを確認してください
