# 仕様書: ワイヤレスタリー子機 & タリープロトコル

> 親仕様書: [`00-system-overview.md`](./00-system-overview.md) / 共通プロトコルは親仕様書 §4.3 を参照。

## 1. 背景・目的

- カメラ頭に載せるワイヤレスタリー子機。PC常駐アプリが送出する独自UDPブロードキャストを受信し、自チャンネルの状態に応じて赤/緑LEDを点灯する。
- 子機側の処理は極限まで軽量にし（数バイト受信→LED制御のみ）、開発・運用を容易にする。

## 2. 機能要件

- [ ] Wi-Fiで指定LANに接続し、UDPポート **9999** のブロードキャストを待ち受ける。
- [ ] 受信ペイロード（親仕様書 §4.3）を解析し、自チャンネル(`ch`)の状態を判定:
  - `active_pgm` に自chが含まれる → **赤LED点灯**（Program / オンエア）
  - `active_pvw` に自chが含まれる → **緑LED点灯**（Preview）
  - どちらにも無い → **消灯**
- [ ] 自チャンネル番号を設定可能にする（DIPスイッチ / 設定保存 / 簡易設定UIのいずれか）。
- [ ] 一定時間パケット未受信（タイムアウト）時のフェイルセーフ表示（例: 低速点滅で「通信断」を示す）。
- [ ] （任意）バッテリー残量表示、Wi-Fi接続状態表示。

## 3. 技術スタック

- **MCU**: ESP32-C3 / ESP8266（安価Wi-Fi）または M5Stack / M5Stamp（液晶付き）
- **開発環境**: Arduino Framework または ESP-IDF
- **電源**: リチウム電池（充電回路 + 昇圧）想定
- **筐体**: 3Dプリント製、カメラのコールドシューにマウント

## 4. 非機能要件

- 受信→LED反映は即時（体感ゼロ遅延）。
- ファームは軽量（コアロジックは数十行規模）。
- バッテリー駆動時間を考慮した省電力設計（LED輝度調整・スリープ検討）。

## 5. UI/UX 設計方針

- 屋外/暗所どちらでも視認できるLED輝度（可変が望ましい）。
- 赤=本番、緑=プレビュー、消灯=待機、点滅=通信断、を厳守。
