# 仕様書: Pico 2W コントローラー & タリー抽出ファームウェア

> 親仕様書: [`00-system-overview.md`](./00-system-overview.md) / 共通プロトコルは親仕様書 §4 を参照。

## 1. 背景・目的

- 自作スイッチャーの物理コントローラー兼、システムのハードウェア統括ノード。
- 各スイッチングモジュール内のマイコンを **Pico 2W (RP2350 + Wi-Fi)** が統括し、**外部（PC・ネットワーク）と通信するのは Pico 2W のみ**とする（親仕様書 §2.1）。
- 物理ボタン入力の検知・送信、HDMIラインからの物理タリー抽出、（検討）Wi-Fi経由の独自プロトコル接続を担う。

## 2. 機能要件

### 2.1 物理キー入力スキャン
- [ ] スイッチャー操作用物理ボタン（キーマトリクス、最大16ボタン想定）をチャタリング防止しつつ常時スキャン。
- [ ] 押下キーIDを、接続先（PC直結時＝USB / スマホ経由時＝USB-OTG）へ送信。
- [ ] 送信は USB-HID または USB-CDC（シリアル）で行う。イベント形式は親仕様書 §4.1 に準拠（`controller_id` を付与）。
- [ ] 複数コントローラー識別: RP2350のUnique Board ID もしくは設定でメイン/サブを区別できるようにする。

### 2.2 モジュール内マイコンの統括制御 【内部制御 / 詳細は後日】
- [ ] Pico 2W が各モジュール内マイコンを統括制御する。
- [ ] 外部への通信窓口は Pico 2W に一本化する（モジュール内マイコンは外部通信しない）。
- [ ] **TBD**: Pico 2W ↔ モジュール内マイコン間の内部バス（I2C / UART / SPI 等）・アドレッシング・コマンド体系は別途詳細化する。本節は追って更新する。

### 2.3 HDMI DDCライン・スニッフィング（タリー抽出）
- [ ] HDMIコネクタの 15番ピン(SCL) / 16番ピン(SDA) / 17番ピン(GND) に接続。
- [ ] ATEM Mini ↔ カメラ間の DDC/I2C パケットをパッシブにスニッフィング（盗聴）。
- [ ] Blackmagic Camera Control Protocol をデコードし、自カメラ宛のタリーON/OFF（Red/Green）を検知。
- [ ] 検知したタリー状態で GPIO接続のタリーLED（赤/緑）を点灯し、同時にUSBシリアル経由で状態を通知。
- [ ] 高速TMDS線には一切触れず、低速制御線(13/15/16/17)のみ分岐する（映像信号への非干渉を保証）。

### 2.4 Wi-Fi経由の独自プロトコル接続（検討）
- [ ] Pico 2W の Wi-Fi を用い、スマホを介さず直接 PC常駐アプリ（WebSocket/UDP）へ接続する経路も検討。
- [ ] タリーUDPブロードキャスト（親仕様書 §4.3）を Pico 2W 自身が受信し、内蔵/接続LEDを制御する用途も想定。

## 3. 技術スタック

- **MCU**: Raspberry Pi Pico 2W（RP2350 + Wi-Fi (CYW43)）
- **開発環境**: Pico SDK（C/C++）
- **USBスタック**: TinyUSB（USB-HID または USB-CDC）
- **I2C**: ハードウェアI2C（例: GP4=SDA, GP5=SCL）でDDCラインをモニタリング
- **Wi-Fi**: lwIP スタック（Pico SDK同梱）

## 4. 非機能要件

- ボタン→送信のレイテンシは実質ゼロ（数ms以内）。
- DDCスニッフィングはパッシブで、ATEM↔カメラ間通信を阻害しない。
- USB直結／USB-OTG（スマホ）どちらでも同一ファームで動作する。

## 5. ハードウェア接続（タリー抽出ドングル）

```text
[ ATEM Mini ] ──(HDMI)──→ [ HDMIブレイクアウト基板 ] ──→ [ モニター/カメラ ]
                                    │ 15pin(SCL) ─→ Pico 2W GP(SCL)
                                    │ 16pin(SDA) ─→ Pico 2W GP(SDA)
                                    └ 17pin(GND) ─→ Pico 2W GND
                                                      └→ タリーLED(赤/緑) / ワイヤレスタリー送信
```

- 高速信号ライン(TMDS)は結線せずストレート通過。低速制御線のみピンソケットで分岐。
